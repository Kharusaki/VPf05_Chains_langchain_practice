# LangChain CodeGen Demo

Учебный проект: генерация Python-кода через многошаговую цепочку на LangChain (LCEL).
Скрипт принимает задачу в терминале и прогоняет её через 4 этапа, показывая результат каждого.

## Что умеет

Цепочка состоит из четырёх шагов, где выход каждого становится входом следующего:

1. **Анализ задачи** — требования, входы/выходы, граничные случаи.
2. **Подбор инструментов** — стандартная библиотека или внешние пакеты, с обоснованием.
3. **Реализация** — генерация кода на Python.
4. **Ревью** — проверка корректности, граничных случаев и стиля, вердикт и замечания.

Данные между шагами передаются через `RunnablePassthrough.assign()`: каждый шаг видит только те поля, которые ему нужны (например, ревьюер получает задачу и код, но не анализ и не список инструментов).

## Структура

    .
    ├── main.py          # сборка цепочки и запуск
    ├── prompts.py       # тексты промптов (отдельно от логики)
    ├── .env             # OPENAI_API_KEY (не коммитится)
    ├── .gitignore
    └── requirements.txt

## Установка

    python -m venv venv
    source venv/bin/activate      # Windows: venv\Scripts\activate
    pip install -r requirements.txt

Создайте файл `.env` в корне проекта:

    OPENAI_API_KEY=sk-...

Ключ подхватывается `ChatOpenAI` автоматически из переменной окружения `OPENAI_API_KEY`.

## Запуск

    python main.py

Скрипт интерактивно запросит задачу, например:

    Введите задачу для генерации кода: функция, проверяющая, является ли строка палиндромом

И выведет результат по каждому из четырёх шагов.

## Стек

- Python 3.10+
- LangChain (LCEL, `RunnablePassthrough`)
- `langchain-openai` (`ChatOpenAI`, модель `gpt-4o-mini`)
- `python-dotenv`

## Заметки

- `temperature=0` на всех шагах — для генерации кода важна предсказуемость.
- Промпты вынесены в `prompts.py`, чтобы менять формулировки, не трогая логику.
- Проект учебный: ревью-шаг **не применяет** замечания автоматически (это был бы уже цикл на LangGraph).
